10. Limitations, Risks, and Lessons Learned

10.1 Limitations

  • Syntactic, Not Semantic: The verifier enforces structure, syntax, and presence of sections, but does not verify if instructional prose is factually accurate.
  • Filesystem Bound: Requires local filesystem access to watch directories; currently lacks direct cloud object store (S3/Azure Blob) polling.

10.2 Operational Risks

  • Schema Divergence: Uncoordinated master template edits can immediately cause all incoming documents to fail validation.
  • Author Frustration: Author friction if error diagnostics are misunderstood (mitigated by providing actionable fixes on every error).

10.3 Lessons Learned

  • Deterministic Primacy: Never rely on LLMs for deterministic syntax checking. Deterministic Python regex evaluation is 1000x faster, zero-cost, and 100% reproducible.
  • Presentation Decoupling: Decouple presentation timestamps from machine filenames early to maintain clean UI reporting.
  • Flexible Mail Relays: Enterprise SMTP authentication policies frequently block direct server-to-server mail; maintaining flexible relay support is essential.
