11. Proposed Plan, Future Work, and Roadmap

11.1 Phase 2: Ingestion Pipeline Hook (RAGFlow Direct API)

Automate direct dispatch of verified documents from verified/ into RAGFlow document datasets via REST API upon successful verification, completing the automated ingestion lifecycle.

11.2 Phase 3: Autonomous AI Auto-Fixer Agent

Over 70% of document failures stem from mechanical flaws (missing blank lines around headings, tabs instead of spaces, missing language tags). We propose an automated pre-quarantine fixer that sanitizes whitespace, injects blank padding, infers code languages, and re-verifies automatically.

11.3 Phase 4: Semantic LLM Quality Reviewer

An optional, gated LLM review step executed only after deterministic checks pass to evaluate whether the title matches content, procedures have meaningful expected results, and evaluation questions are answerable from the document.

11.4 Phase 5: Centralized Telemetry & Dashboard

Build a lightweight web dashboard displaying batch verification trends, top rule failure distributions, and pipeline throughput.
