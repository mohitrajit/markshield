4.2 Pipeline Processing Stages

  1. Intake Staging: Incoming Markdown files and referenced image assets are dropped into inbox/.
  2. Settlement Buffer: The daemon checks file modification times against SETTLE_SECONDS (default 5s). Files currently being written or copied over network shares are skipped until the transfer finishes.
  3. Rule Compilation: rules.yaml is loaded and RAG-SAMPLE-MASTER-TEMPLATE.md is introspected to construct dynamic schema definitions.
  4. Verifier Engine: verifier.py executes 10 sequential inspection passes against the document text.
  5. File Routing: If 0 errors are found, the document and its local images are moved to verified/. If errors are detected, the document is moved to failed/ and a <stem>.report.txt is emitted.
  6. Reporting & Notification: openpyxl synthesizes a multi-tab workbook with Summary and per-document tabs; render_html() builds an executive status card; send_email() dispatches the report via Gmail relay.
